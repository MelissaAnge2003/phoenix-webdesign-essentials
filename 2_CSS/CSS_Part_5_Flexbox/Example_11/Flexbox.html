1. Flexbox is a CSS technique that allows you to quickly and easily arrange the layout of blocks on your website. With flexbox, the width of the blocks doesn't matter; they will automatically use the available space in the most logical and efficient way.

2. Items within a flex container have flexible dimensions. They can grow to fill unused space, or shrink to fit within the boundaries of the parent element.

3. Flexbox is extremely popular. Bootstrap has been using flexbox instead of float since version 4 to create responsive layouts.
